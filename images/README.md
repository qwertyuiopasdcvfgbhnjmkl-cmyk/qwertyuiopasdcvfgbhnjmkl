# 圖片放置說明

把作品照片放在這個資料夾，檔名請用以下規則。

## 檔名對照

| 作品 | 建議檔名 | 建議尺寸 |
|---|---|---|
| 《醉雞》 | `zuiji-01.jpg`、`zuiji-02.jpg` | 寬 1600px 以上 |
| 《藍眼淚》 | `lanyanlei-01.jpg`、`lanyanlei-02.jpg` | 寬 1600px 以上 |
| 《秋夜有感》 | `qiuyeyougan-01.jpg` | 寬 1600px 以上 |

## 注意事項

- **用英文數字檔名。** 中文檔名在部分主機與瀏覽器可能出現編碼問題。
- **建議寬度 1600px 以上**，因為網站會以 896px 寬度顯示，高解析度在高分螢幕上較清楚。
- **建議用 JPG 或 WebP**，單張控制在 500KB 以內，網站才不會卡。
- **建議比例 3:2 或 4:3 橫幅**，與版面一致。
